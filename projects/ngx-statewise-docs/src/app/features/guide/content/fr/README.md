# Traductions françaises du guide

Chaque fichier de `../en/` peut être traduit ici sous le même nom, puis déclaré
dans le `content` de sa page dans `../../guide-pages.ts` :

```typescript
content: { en: effectsEn, fr: effectsFr },
```

Tant qu'une page n'a pas de version française, le site sert l'anglais et
affiche un bandeau le disant. Rien d'autre n'est à faire.
