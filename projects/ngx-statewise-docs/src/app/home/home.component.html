Angular state management

ngx-statewise

Signals for state, actions for intent, effects for everything else. Simpler than NgRx, more structured than doing it by hand.

Get started Read the guide 
npm install ngx-statewise

The whole flow

  1. Action carries the intent and its payload.
  2. Updater writes the state, synchronously.
  3. Effect runs the side work, on state already up to date.
  4. Manager exposes the signals and dispatches, in its own scope.
